# 🚀 INICIO RÁPIDO - Proyecto Integrador

## ⚡ TL;DR (Solo 4 pasos)

### 1. Abre Terminal en Cursor

```
Ctrl + ` (backtick)
```

### 2. Activar Entorno Virtual

```bash
source venv/bin/activate
```

### 3. Abre el Notebook en Cursor

```
Abre: mlops_pipeline/src/Cargar_datos.ipynb
```

### 4. Ejecuta las celdas

```
Shift + Enter para cada celda
```
